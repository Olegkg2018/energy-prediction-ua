⚡ Про проект

Веб-програма для прогнозування ціни електроенергії в Україні для юридичних осіб. Система використовує машинне навчання (XGBoost) для прогнозу погодинних цін на ринку "на добу наперед" (РДН) та лінійне програмування (PuLP) для оптимізації заряду/розряду промислових батарей.

🧠 Методи

🔮 XGBoost + LSTM Ensemble (прогноз цін)

Ансамбль XGBoost (800 дерев) + LSTM (128→64 нейрони) з оптимальними вагами. 134 ознаки:

  • Часові (14): hour, dayofweek, month, sin/cos_hour, sin/cos_month, sin/cos_dayofyear
  • Фур'є (10): гармоніки 2-го та 3-го порядку для години та місяця
  • Календарні (12+): вихідні, свята, bridge days, сезон, опалювальний сезон
  • Погода (10): температура, вологість, хмарність, радіація, heating/cooling degree
  • ВДЕ (5): solar_index, wind_index, renewable_index, solar/wind interactions
  • ОЕС (14): частки АЕС/ТЕС/ГЕС/СЕС/ВЕС, total_gen_mw, generation interactions
  • Цінові (38+): лаги 2h-504h, rolling stats (mean/std/min/max/median/skew/kurt), EWM, EMA, TEMA, Bollinger Bands, momentum, ROC
  • Газ (6): TTF, НАФТОГАЗ, spark spread, momentum
  • Ринок (2): ВДР-РДН spread/ratio

⚙️ PuLP (оптимізація батареї)

Лінійне програмування для максимізації прибутку від заряду/розряду промислової батареї. Враховано:

  • Обмеження потужності (1 МВт) та ємності (4 МВт·год)
  • ККД заряду/розряду (92%)
  • Тарифи на передачу (150 грн) та диспетчеризацію (50 грн)
  • Ліміт циклів (до 2 на добу)
  • Ручні фактори (ризик прильотів, відключення АЕС)
  • Фолбек на простий сорт-алгоритм при відсутності PuLP

🔀 Cross-Validation (TimeSeriesSplit)

Часовий кросс-валідація (5 фолдів) для оцінки стабільності моделі без data leakage:

  • Фолд 1: тренування на перших 20% → тест на наступних 20%
  • Фолд 2: тренування на перших 40% → тест на наступних 20%
  • ... до фолду 5 (тренування на 80% → тест на останніх 20%)

Кожна хвиля тестується виключно на ПІЗНІШИХ даних, ніж тренувальна — імітує реальний сценарій прогнозу майбутнього.

Метрики по фолдах: MAE, RMSE, R². Середні значення показують реальну точність моделі.

🔁 Спред ВДР-РДН

Внутрішньодобовий ринок (ВДР) дозволяє коригувати позиції після закриття РДН (до 12:00). Заявки подаються з 15:00 D-1 до закриття воріт (за 60 хв до реального часу).

Для батареї: купівля на ВДР дешевше + продаж на РДН дорожче = додатковий арбітраж. Спред ВДР-РДН — індикатор дефіциту/профіциту.

📅 Щоденний гайд: максимізація доходу від УЗЕ

Мета: щоденний прибуток від арбітражу цін РДН/ВДР через 1 МВт / 4 МВт·год батарею. Типовий дохід: $450-480/день (1.5 циклу), $150-160K/рік (330 днів).

Крок 1: Оновлення даних (06:00-07:00, щоранку)

Що робити: Відкрити дашборд → натиснути "Завантажити дані OREE" та "Перетренувати модель"
Навіщо: OREE публікує фінальні ціни попереднього дня ~06:00. Модель потребує свіжих даних для точного прогнозу.
Альтернатива: POST /api/refresh_data — оновлює всі кеші (погода, OREE, ВДР, генерація).

Крок 2: Прогноз на завтра (07:00-12:00)

Що робити: Сторінка "Прогноз" → обрати дату завтра → "Отримати прогноз"
Що дивитись:
  • Години заряду (ціна < 500 грн) — найдешевші години для купівлі
  • Години розряду (ціна > 5000 грн) — найдорожчі години для продажу
  • Спред = max(розряд) - min(заряд) — цільовий спред > 3000 грн/МВт·год
  • Профіцит (10 грн) — якщо є години < 20 грн, максимально зарядити батарею

Крок 3: Оптимізація батареї (07:00-13:00)

Що робити: Натиснути "Оптимізувати батарею" → переглянути графік та таблицю
Оптимізатор (PuLP) визначає:
  • Точний розклад заряду/розряду по годинах (до 2 циклів/добу)
  • Прогнозований дохід = сума (розряд × ціна) - сума (заряд × ціна) - тарифи
  • SoC timeline — рівень заряду батареї протягом доби

Крок 4: Встановлення ручних факторів (якщо потрібно)

Коли застосовувати:
  • "Відключення АЕС" — якщо відомо про аварійний зупин атомного блоку (ціни +30%)
  • "Ризик прильотів" > 50% — підвищує нічні ціни, коригує розклад заряду
Ці фактори впливають на effective_prices в оптимізаторі, зміщуючи розклад.

Крок 5: Виконання (протягом доби)

Що робити: Слідувати розкладу з оптимізатора. Більшість дій автоматизується через SCADA/EMS батареї.
Типовий режим (1.5 циклу):
  • 00:00-06:00 — нічна зарядка (ціна мінімальна, ~2900-3500 грн)
  • 08:00-11:00 — ранковий пік → розряд (ціна ~6400-7100 грн)
  • 11:00-15:00 — сонячний профіцит → дозарядка (ціна знижується)
  • 18:00-23:00 — вечірній пік → розряд (ціна максимальна)

Крок 6: Аналіз та корекція (вечір, після 23:00)

Що робити: Порівняти прогнозовані ціни з реальними на сторінці "Прогноз" → вкладка "Порівняння прогнозу з реальними цінами OREE"
Метрики для відстеження:
  • MAE похибки — ціль < 300 грн
  • Фактичний дохід — порівняння з прогнозованим
  • Пропущені можливості — години де реальна ціна була < 50 грн, а ми не зарядили

Крок 7: Перетренування моделі (щотижня)

Що робити: Щопонеділка — "Перетренувати модель" + "Cross-Validation"
Навіщо: модель адаптується до нових цінових патернів (сезонність, зміна генерації, нові СЕС/ВЕС). Cross-Validation показує стабільність.
Цільові метрики: R² > 0.95, MAE < 300 грн, CV MAE в межах ±20% від test MAE.

📋 Типові цінові патерни

Коли очікувати ціну 10 грн?

Ціна 10 грн/МВт·год з'являється при профіциті генерації в ОЕС України. Основні фактори:

  • Весняно-літній період: надлишок сонячної генерації вдень
  • Вітряна погода: ВЕС дають надлишок вночі
  • Вихідні та свята: зниження промислового споживання
  • Відсутність атомних блоків в ремонті: базова генерація не знижується
  • Тепла погода: зниження споживання на опалення

Типові години профіциту: 10:00-15:00 (максимум СЕС) та 02:00-05:00 (нічний мінімум споживання)

Динаміка цін за роками

Середня ціна на РДН має стійкий висхідний тренд:

  • 2023: 3 388 грн/МВт·год
  • 2024: 4 402 грн/МВт·год
  • 2025: 5 147 грн/МВт·год
  • 2026: 6 799 грн/МВт·год
