# Energy Prediction UA

Прогнозування ціни електроенергії в Україні для юридичних осіб.
XGBoost модель + PuLP оптимізація батареї (УЗЕ) + Flask веб-інтерфейс.
**Ціль:** арбітраж електроенергії через установку зберігання енергії (УЗЕ) 1 МВт / 4 МВт·год.

---

## Ідея проекту

### Ринок електроенергії України для юр. осіб

Юридичні особи в Україні купують електроенергію на **Ринку «на добу наперед» (РДН)** та **Внутрішньодобовому ринку (ВДР)** через оператора ОРЕЕ (https://www.oree.com.ua). Ціна змінюється щогодини і залежить від балансу попиту та пропозиції в Об'єднаній енергетичній системі (ОЕС) України.

**Ключові особливості ринку:**
- **Почасове ціноутворення** — 24 цінові інтервали щодоби
- **Прайс-кепи НКРЕКП** — обмеження цін (нижній/верхній), які регулюють маржинальність
- **Висока волатильність** — ціна може змінюватись у 3-4 рази протягом доби
- **Сезонність** — літній профіцит сонячної генерації vs зимовий дефіцит

### Арбітраж електроенергії через УЗЕ (BESS)

Установка зберігання енергії (УЗЕ) потужністю 1 МВт з ємністю 4 МВт·год дозволяє заробляти на різниці цін:

```
Заряд (ніч/профіцит):  ~2 900-3 500 грн/МВт·год  (купуємо дешево)
Розряд (пік):          ~6 400-7 100 грн/МВт·год  (продаємо дорого)
Спред:                 ~3 200-4 500 грн/МВт·год  (~$80-110/МВт·год)
```

**Типовий режим роботи — 1,5 цикли на добу:**
1. **Нічна зарядка** (00:00-06:00) → **Ранковий пік** (08:00-11:00)
2. **Денна зарядка** (11:00-15:00, сонячний профіцит) → **Вечірній пік** (18:00-23:00)

Дохід за цикл: `4 МВт·год × $95 × 85% ККД ≈ $323/день`
Валова виручка: **$450-480/день** (1,5 цикли)

### Обладнання

**УЗЕ 1 МВт / 4 МВт·год на базі Huawei LUNA2000-2.0MWH**
- Промислова літій-залізо-фосфатна (LFP) система
- Контейнерне рішення, 4-годинний накопичувач глибокого циклу
- Термін служби: 12-15 років (5000-6000 циклів до втрати 20% ємності)
- Деталі: https://gigawat.com.ua/ua/p2826140262-ustanovka-nakopleniya-energii.html

## Прогнозування ціни

### Методи

| Метод | Застосування |
|-------|-------------|
| **XGBoost** | Основна модель прогнозу цін РДН на 24 год (43 фічі, квантилі P10/P50/P90) |
| **LSTM** | Перспективний напрям — рекурентна нейромережа для часових рядів (у розробці) |
| **PuLP** | Лінійна оптимізація режимів заряду/розряду батареї (до 2 циклів/добу) |

### Фактори, що впливають на ціну

**Ринкові:**
- Ціна РДН (ринок «на добу наперед») — історичні дані + лагові значення (24h, 168h)
- Ціна ВДР (внутрішньодобовий ринок) — поточна волатильність
- Загальний ринковий коефіцієнт — баланс попиту/пропозиції

**Генерація ОЕС (ENTSO-E / Ukrenergo):**
- Атомна генерація (АЕС) — ~50-60% базового навантаження. **Відсутність ядерної генерації** різко підвищує ціну.
- Теплова генерація (ТЕС) — маневрова потужність, залежить від ціни газу/вугілля
- Гідрогенерація (ГЕС/ГАЕС) — балансування піків
- **Сонячні станції (СЕС)** — денний профіцит, знижують ціну вдень. **Прильоти по СЕС** — різке зростання ціни.
- Вітрові станції (ВЕС) — нестабільна генерація

**Погодні (OpenWeather OneCall 3.0):**
- Хмарність та сонячна радіація — вплив на генерацію СЕС
- Прогноз швидкості вітру — вплив на генерацію ВЕС
- Температура — попит на охолодження/опалення (demand_proxy, cooling_demand, heating_demand)
- Індекс ВДЕ по 5 зонах (Південь, Запоріжжя, Дніпро, Одеса, Карпати)

**Календарні:**
- Виробничий та відпускний календар — вихідні (is_weekend) та святкові дні (is_holiday)
- Час доби (hour) — денний профіцит vs вечірній пік
- Сезон (місяць, день року) — циклічні коливання попиту

**Економічні:**
- **Ціни на природний газ (TTF/НАФТОГАЗ)** — вплив на собівартість ТЕС
- Прайс-кепи НКРЕКП — регуляторні обмеження

### Ознаки моделі (43 фічі)

**Базові (14):** hour, dayofweek, month, day, is_weekend, is_holiday, sin_hour, cos_hour, sin_month, cos_month, sin_dayofyear, cos_dayofyear, sin_hour_of_week, cos_hour_of_week

**Погода (4):** temperature, temperature_squared, humidity, solar_radiation

**ВДЕ (3):** solar_index, wind_index, renewable_index

**ОЕС (7):** nuclear_share, thermal_share, hydro_share, solar_share, wind_share, res_share, total_gen_mw

**Тренд (1):** days_since_epoch

**Інтеракції (8):** solar_irradiance, solar_intensity, is_solar_dip_hour, demand_proxy, cooling_demand, heating_demand, solar_x_hour, wind_x_hour

**Цінові (6):** price_lag_24h, price_lag_168h, price_rolling_mean_24h, price_rolling_std_24h, price_delta_1h, price_vs_yesterday

## Фінансова модель проекту

### CAPEX (капітальні витрати)

| Стаття | Вартість |
|--------|----------|
| BESS (LFP, контейнер) 4 000 кВт·год × $220-260/кВт·год | $880 000 – $1 040 000 |
| Інтеграція та інфраструктура (інвертори, ТП, пожежогасіння) | $150 000 – $250 000 |
| **Разом CAPEX** | **$1 030 000 – $1 290 000** |

### Дохід

| Джерело доходу | Річна оцінка |
|----------------|--------------|
| Арбітраж (1,5 циклу/добу, 330 днів) | $150 000 – $160 000 |
| Резерви підтримання частоти (РПЧ/аРВЧ) | $30 000 – $50 000 |
| **Всього операційний дохід** | **$180 000 – $210 000** |

### OPEX та EBITDA

| Параметр | Значення |
|----------|----------|
| Операційні витрати (сервіс, оренда, охолодження) | $20 000 – $25 000/рік |
| **Чистий прибуток (EBITDA)** | **$160 000 – $185 000/рік** |
| Період окупності (Payback) | **6,2 – 7,2 років** |

### Порівняння зі світовими ринками

| Регіон | Доходність на 1 МВт/рік |
|--------|------------------------|
| **Україна** (наш проект) | **$160 000 – $185 000** |
| Європа (ISEA 2026) | €135 000 – $145 000 |
| Техас, ERCOT (Flower Valley) | $90 000 – $180 000 |
| Німеччина (Enervis) | €145 000 |

**Приклади реальних установок:**
- **Flower Valley (Техас, ERCOT):** BESS балансує систему, арбітраж + допоміжні послуги, дохід до $180 000/МВт
- **Батарея Снайдер (Техас, 9,9 МВт):** $96/кВт ($960 000 для 10 МВт) при пікових цінах до $5 000/МВт·год
- **Німеччина:** арбітраж всередині дня — 60-87% доходу накопичувачів

## API Endpoints

| Endpoint | Опис |
|----------|------|
| `/` | Дашборд |
| `/predict` | Прогноз + оптимізація |
| `/about` | Інформація про проект |
| `/api/stats` | Статистика моделі (MAE, R², ознаки) |
| `/api/model_info` | Інформація про модель |
| `/api/predict?date=YYYY-MM-DD` | Прогноз цін на добу (24 год) |
| `/api/predict_multi?days=3` | Прогноз на декілька діб |
| `/api/optimize?date=YYYY-MM-DD&capacity=4&power=1` | Оптимізація батареї (PuLP, до 2 циклів) |
| `/api/factors?date=YYYY-MM-DD` | Аналіз факторів впливу на ціну |
| `/api/factors/manual` | GET/POST ручних факторів (nuclear_outage, missile_risk) |
| `/api/generation_mix` | Поточна генерація ОЕС по типах |
| `/api/generation_timeseries` | Часовий ряд генерації за 7 днів |
| `/api/renewable_index` | Індекс ВДЕ по 5 зонах + прогноз |
| `/api/oree_prices` | Історичні ціни РДН (60 днів) |
| `/api/idm_prices` | Ціни ВДР (60 днів) |
| `/api/live_prices` | Останні 48 год OREE |
| `/api/forecast_weather` | Прогноз погоди на 3 дні |
| `/api/historical_surplus` | Історичний надлишок генерації |
| `/api/forward_curve?days=7` | Forward крива на N діб |
| `/api/position_value?buy=&sell=&volume=&days=` | Вартість позицій купівлі/продажу |
| `/api/refresh_data` | Примусове оновлення всіх кешів |
| `/train` (POST) | Перетренувати модель |

## Архітектура

```
energy-prediction-ua/
├── app.py                     # Flask сервер (22+ REST роутів)
├── collectors/
│   ├── oree.py                # Парсинг OREE (РДН + ВДР), години 1-24 → 0-23
│   ├── weather.py             # OpenWeather OneCall 3.0 + кеш + інтерполяція 3→1h
│   ├── renewable_index.py     # Індекси ВДЕ (5 зон + прогноз)
│   └── generation_mix.py      # ENTSO-E / Ukrenergo генерація ОЕС
├── model/
│   ├── train.py               # XGBoost навчання (43 фічі + P10/P50/P90 квантилі)
│   ├── predict.py             # Прогноз на добу + згладжування ±2 год
│   └── model.pkl              # Натренована модель
├── optimizer/
│   └── scheduler.py           # PuLP батарея (до 2 циклів/добу, duck curve)
├── data/
│   ├── loader.py              # Завантаження + feature engineering (43 фічі)
│   ├── prices_2025.csv        # Історичні ціни (статика)
│   ├── oree_prices.feather    # OREE кеш
│   ├── cache.feather          # Об'єднаний датасет
│   └── forecast_cache.json    # Погодний кеш
├── templates/                 # Jinja2 + Plotly (дашборд, прогноз, about, порівняння)
├── static/                    # CSS/JS
├── Dockerfile
└── docker-compose.yml
```

## Швидкий старт

### Через Docker (рекомендовано)

```bash
git clone https://github.com/Olegkg2018/energy-prediction-ua.git
cd energy-prediction-ua
docker compose up -d --build
```

Відкрити http://localhost:5000

### Без Docker

```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
python collectors/data_generator.py
python app.py
```
